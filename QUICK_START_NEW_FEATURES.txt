STEP 1: RESTART YOUR SERVER
═══════════════════════════════════════════════════════════

If server is running:
1. Press Ctrl + C to stop
2. Type: npm start
3. Wait for "Server running" message

If server is not running:
1. Open terminal in project folder
2. Type: npm start
3. Wait for "Server running" message

STEP 2: HARD REFRESH YOUR BROWSER
═══════════════════════════════════════════════════════════

Press: Ctrl + F5

This loads all new code fresh!

STEP 3: SEE THE NEW FEATURES
═══════════════════════════════════════════════════════════

✅ FEATURE 1: LIVE IMPACT DISPLAY (Homepage)

Where: Right below hero section
What: 4 animated boxes showing:
  - 💰 Total Raised This Month
  - ❤️ Donations Received
  - 🙏 Generous Donors
  - 🌍 Lives Impacted

Cool Effects:
  - Numbers count up from 0
  - Boxes hover and lift
  - Auto-updates every 30 seconds
  - Purple gradient background

───────────────────────────────────────────────────────────

✅ FEATURE 2: ANONYMOUS DONATIONS (Donation Form)

Where: Donation form, above submit button
What: Checkbox "Make my donation anonymous"

How to Use:
  1. Fill donation form
  2. Check the box
  3. Complete payment
  4. Your name shows as "Anonymous Donor"

Privacy: Email kept for receipt, name hidden publicly

───────────────────────────────────────────────────────────

✅ FEATURE 3: PERSONAL MESSAGES (Donation Form)

Where: Donation form, below cause selection
What: Text field "Personal Message (Optional)"

Examples:
  - "In memory of my mother"
  - "Keep up the great work!"
  - "Hope this helps families"

Message appears on receipt!

───────────────────────────────────────────────────────────

✅ FEATURE 4: DOWNLOADABLE RECEIPTS (After Payment)

When: After successful M-Pesa payment
What: "Download Receipt" button appears

How to Use:
  1. Complete donation successfully
  2. See success message
  3. Click "Download Receipt"
  4. Open downloaded HTML file
  5. Press Ctrl + P to print as PDF

Receipt Includes:
  - Receipt number (M-Pesa ID)
  - Donor name (or "Anonymous")
  - Date & time
  - Amount donated
  - Selected cause
  - Your personal message
  - Organization details
